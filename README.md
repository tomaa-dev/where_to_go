# Пишем Яндекс.Афишу

Проект представляет собой интерактивную карту Москвы, на которой все известные виды активного отдыха с подробными описаниями и комментариями.

### Как запустить

Для запуска сайта вам понадобится Python третьей версии.

Скачайте код с GitHub. Затем установите зависимости

```sh
pip install -r requirements.txt
```

Запустите сервер разработчика, он будет доступен [по ссылке](http://127.0.0.1:8000/)

```sh
python3 manage.py runserver
```

В проекте реализована management-команда для автоматизации загрузки новых локаций:

```sh
python manage.py load_place http://адрес/файла.json
```

### Переменные окружения

Часть настроек проекта берётся из переменных окружения. Чтобы их определить, создайте файл `.env` рядом с `manage.py` и запишите туда данные в таком формате: `ПЕРЕМЕННАЯ=значение`.

Доступны 2 переменные:
- `DEBUG` — дебаг-режим. Поставьте True, чтобы увидеть отладочную информацию в случае ошибки.
- `SECRET_KEY` — секретный ключ проекта.
